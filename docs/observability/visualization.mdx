Understanding complex DAGs can be difficult. HyperNodes provides built-in visualization tools to help you see the structure of your pipeline.

## The `.visualize()` Method

You can visualize any pipeline using the `.visualize()` method.

```python
pipeline.visualize()
```

By default, this generates an **interactive JavaScript visualization** using React Flow:

- **Jupyter Notebooks**: Renders an interactive diagram directly in the cell with expand/collapse, pan, and zoom.
- **Scripts**: Returns HTML string that can be saved or displayed.

### Static Graphviz Mode

For a static SVG diagram, use `engine="graphviz"`:

```python
pipeline.visualize(engine="graphviz")
```

- **Jupyter Notebooks**: Renders the SVG directly in the cell.
- **Scripts**: Returns an SVG string.

### Saving to File

```python
# Interactive HTML
pipeline.visualize(filename="my_pipeline.html")

# Static SVG
pipeline.visualize(filename="my_pipeline.svg", engine="graphviz")
```

## Customization

### Orientation (Graphviz only)

Change the layout direction with `orient`:

```python
pipeline.visualize(engine="graphviz", orient="LR")  # Left-to-Right (default is Top-Bottom)
```

### Nesting Depth

Control how deep to expand nested pipelines.

- `depth=1`: Show top-level nodes and collapsed sub-pipelines.

![Collapsed Pipeline](/docs/assets/pipeline_nested_collapsed.svg)

- `depth=None`: Fully expand all nested pipelines.

![Expanded Pipeline](/docs/assets/pipeline_nested_expanded.svg)

```python
pipeline.visualize(depth=None)
```

### Styles (Graphviz only)

HyperNodes comes with visual styles for Graphviz output.

```python
pipeline.visualize(engine="graphviz", style="modern")
```

## Legend (Graphviz only)

Enable a legend to explain node shapes and colors.

```python
pipeline.visualize(engine="graphviz", show_legend=True)
```
